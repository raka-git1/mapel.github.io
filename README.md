Sistem Data Sekolah
Project ini merupakan aplikasi web sederhana untuk mengelola data siswa dan mata pelajaran menggunakan PHP dan MySQL. Project dijalankan menggunakan Laragon.

Fitur
Data siswa dapat ditambah, dilihat, diedit, dan dihapus.
Data mata pelajaran dapat ditambah, dilihat, diedit, dan dihapus.
Project menggunakan konsep CRUD.
Teknologi
PHP untuk proses aplikasi.
MySQL untuk database.
HTML untuk tampilan dan form.
MySQLi untuk koneksi database.
Laragon untuk menjalankan project secara lokal.
File Utama
config.php untuk koneksi database.
index.php untuk halaman utama.
form-daftar.php dan proses-pendaftaran.php untuk menambah data siswa.
list-siswa.php untuk menampilkan data siswa.
form-edit.php dan proses-edit.php untuk mengedit siswa.
hapus.php untuk menghapus siswa.
form-pelajaran.php dan proses-mapel.php untuk menambah mata pelajaran.
list-mapel.php untuk menampilkan mata pelajaran.
form-edit-mapel.php dan proses-edit-mapel.php untuk mengedit mata pelajaran.
hapus-mapel.php untuk menghapus mata pelajaran.

Alur
Data dimasukkan melali form, kemudian diproses oleh file PHP dan disimpan ke database. Data yang tersimpan dapat ditampilkan, diedit, atau dihapus melalui halaman yang tersedia.
Database yang digunakan adalah pendaftaran_siswa dengan tabel calon_siswa dan mata_pelajaran.
Cara Menjalankan
Letakkan project di folder:
C:\laragon\www\mapel.github.io
Jalankan Apache dan MySQL melalui Laragon, buat database pendaftaran_siswa, lalu buka:
http://localhost/mapel.github.io/
